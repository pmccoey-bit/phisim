# PHISIM Student Information and Testimonial

Source: `2026 Student testimonial form.docx`, Step 3 Generate letters for Student Nominations.

Open `dist/index.html` locally, or use the privately published Site preview.

The form retains the source fields. Dates use the latest `2027 PHISIM Scholarship Process Dates.docx`: testimonial and photo return by Friday, February 26, 2027; recognition Tuesday, April 6, 2027. The graduation-class restriction is copied from the source form, not independently determined.

Annual display settings are together in `dist/app.js` as `SETTINGS`.

Completed responses can be reviewed, downloaded as text, copied, printed/saved as PDF, or placed in a user-controlled email draft addressed to mccoey@lasalle.edu. The student must send the email in their email app and attach a JPEG headshot if needed. There is no automatic email, photo upload, server submission storage, or spreadsheet write-back in this version.

Inputs remain in page memory. They are not stored in browser local storage or sent by the form to a server. Closing/reloading before download or email discards them.
