# PHISIM Student Scholarship Nomination Form

Blank web form based on `2026_PHISIM_Student_Scholarship_Nomination_Completed_Form.pdf`. The completed student's data, office contact values, signature, DocuSign envelope and certificate are not included. The original signed PDF is unchanged.

Uses the latest 2027 PHISIM Scholarship Process Dates: nominations due Friday, February 12, 2027. The source's graduation-year sequence is advanced to 2027–2028. No automated eligibility or scholarship decisions are made.

Annual settings are together in `dist/app.js` as `SETTINGS`; keep the fallback HTML labels in sync.

Open `dist/index.html` or `dist/Student Scholarship Nomination Form.html` locally. The private Site is a hosted preview.

The review page supports text download, copying, print/save PDF and opening an email draft to mccoey@lasalle.edu. The user must send their email; this version does not automatically email, collect server submissions or update a spreadsheet. Typed names do not recreate the original DocuSign certificate.

Entries remain in page memory and are discarded if the page is closed or reloaded before they are downloaded, copied or emailed. Optional additional information can be left blank.
